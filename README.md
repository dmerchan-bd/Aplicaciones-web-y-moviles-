# Aplicaciones Web y Móviles - 2do Bachillerato Informática

Repositorio oficial de la asignatura **Aplicaciones Web y Móviles**

---
## Descripción
En esta asignatura los estudiantes desarrollaran habilidades para el diseño y construccion de aplicaciones web
El enfoque de la materia está basada en:

- Desarrollo Prácticos de software
- Construcción progresiva de aplicaciones reales
- Trabajo colaborativo y resolución del problema

## Objetivos de la asignatura
Al finalizar el curso, el estudiante será capaz de:
- Crear interfaces funcionales
- Aplicar lógica de pogramación JavaScript
- Desarrollar aplicación interactivas
- Diseñar interfaces responsivas
- Aplicar buenas prácticas de desarrollo
